# F1 Race Prediction & Strategy Simulator (India edition)
Unofficial fan project. Not affiliated with Formula 1. No betting.

## Day 1 quick start
```
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Mac/Linux
pip install -r requirements.txt
python src/build_dataset.py --smoke     # test run
python src/build_dataset.py             # full build
python src/check_data.py                # sanity check + baseline
```
